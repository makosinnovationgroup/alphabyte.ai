### Performance Factors

**Positives:**

- HTTP/2 enabled

- Font preloading with `display: swap`
- Code splitting across page chunks
- Logo SVG preloaded

**Concerns:**
- 5 font files preloaded on every page (~100KB of fonts)
- GA4 script preloaded adding to critical path

- OG images not optimized (570-990KB PNGs)
