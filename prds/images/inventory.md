# Alphabyte AI · Image Plan: All 17 Images

> Every single image we are making. One file. Same format for each.
> Pages not getting any new image (services, tools, about, contact, team) are intentionally NOT listed.
>
> Each entry below contains:
> 1. **Type**: what kind of image it is
> 2. **For**: which page or page-type it belongs to
> 3. **Page contents**: what that page is actually about (so you can judge if the image fits)
> 4. **Where the image appears**: what surrounds it on the page (or off-page, for OGs)
> 5. **Image contents**: what the image will depict, in plain language
> 6. **File spec**: path, dimensions, format

# Brand guardrails (apply to every image above)

- **Colours, only these:** `#00ABF0` blue · `#00FFA6` green · `#171717` ink · `#FAFAFA` canvas · `#EBEBEB` grey · `#E5E5E5` border · `#737373` muted · `#FFFFFF` white
- **Type, only these:** Geist (display + body) · Geist Mono (small labels and IDs)
- **Forbidden across the set:** purple/violet · deep navy `#0D1117` · emoji icons · SVG-drawn faces or scenes · stock photography · neon/cyberpunk · "two professionals shaking hands" · gradient meshes · client logos · real product UIs · real chapter / case / numerical data · government insignia · code screenshots · server-room photography
- **Voice:** plain, contrarian, anti-fluff. British English in any baked-in copy (`programme`, `behaviour`).
